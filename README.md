**软件主要功能**：面向机器人系统集成与工程落地场景的端到端工具包，覆盖“物理仿真→工程化验证→真机部署准备”全流程。

1. **机械臂物理仿真**：基于PyBullet引擎，支持Franka Panda与KUKA iiwa双机型，内置工业、物流、医疗三套场景，运动仿真稳定可复现；
2. **三层解耦架构**：感知、决策、执行三层标准接口相互解耦，算法模块即插即用，单模块替换不影响整体系统；
3. **企业级安全防护**：碰撞检测、紧急停止、异常熔断、输入校验、操作日志审计五层防护，保障仿真与部署全过程安全可控；
4. **多协议通信适配**：TCP、UDP、CAN、EtherCAT、ROS、Modbus六种协议统一适配层，对接真机通信零改造；
5. **三级部署健康检查**：test、pre、prod三级环境自动执行检查项，逐项输出通过结果并自动生成验收报告，真机部署准备状态一目了然；
6. **Sim2Real迁移支持**：多维物理参数域随机化训练，提升策略从仿真迁移到真机的成功率；
7. **图形控制面板**：实时显示关节角度与末端位姿，支持手动遥操作，便于调试与演示；
8. **大模型决策接入与数字孪生可视化**：预留上层智能决策扩展接口，支持数字孪生场景展示。
